# Historical archive

[2019/](2019/) preserves the thesis-era implementation, climate examples,
datasets, generated outputs, plotting scripts, and original bug notes.
These files are historical reference material. They are excluded from the
supported build and do not demonstrate current Koka syntax.

The active project starts at [model.kk](../model.kk), with implementation in
`lib/`, runnable models in `examples/`, and verification in `tests/`.
See the [README](../readme.md) to get started.

The current code uses native Koka effects, typed observations, and reusable
models. Distribution intuition and replay-style MH ideas informed parts of the
rewrite; the archived code is not the current API.
